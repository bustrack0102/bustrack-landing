# angular-parity

## Cuándo usar

Se trabaja en `specs/03-migracion-de-razor-a-angular/`.

## Pasos

1. Inventariar páginas Razor.
2. Definir rutas, guards y sesión.
3. Probar paridad de login/logout.

## Prohibido

- Copiar patrones de otro stack sin adaptación.
- Declarar recursos o endpoints inexistentes.
- Introducir secretos o PII.
